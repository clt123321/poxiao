1. **Rewirable Circuits in Transformers with Loom Attention（通明注意力：Transformer 电路的动态重连）**

   🔬 领域：基础大模型 · Transformer 架构 · 注意力机制 · 热度：HF Daily 2026-11-25

   - **一句话核心贡献**：提出 Loom Attention，让 Transformer 每个 token 都能动态重连内部电路，以仅 2% 的额外算力达到 3 倍以上算力训练的普通 Transformer 性能。
   - **摘要精译**：
     传统 Transformer 的注意力电路在训练完成后基本固定，难以在推理时动态调整信息通路。本文指出信息路由能力与计算效率之间存在尚未挖掘的空间，并尝试让注意力头本身具备「可重连」特性。
     作者提出 loom attention：将每个头的垂直注意力（对先前头输出的注意力，用于获得 query/key/value）与水平注意力（对 token 的注意力）交织在一起，使电路在每个 token 处动态重连。垂直注意力通过归一化、门控的线性注意力在每 token 的矩阵记忆上高效实现，形成第二个残差流，从而将控制流与内容流分离。
     实验表明，在相同 300B token 上训练时，仅增加 2% FLOPs，LoomPythia-2.8B 的平均下游增益约为 mHC-Pythia-2.8B 相对 Pythia-2.8B 的 1.6 倍，并能在 0-shot 持平、5-shot 超越 Pythia-12B。代码已开源。
   - **核心创新点**：
     1. 垂直+水平注意力交织实现动态电路重连
     2. 矩阵记忆作为第二残差流分离控制与内容
     3. 双流架构在 2% 额外算力下达到 3x 效率

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：LoomFormer 双流架构将向量流（控制）与矩阵流（内容）分离。垂直注意力在 per-token 矩阵记忆上进行归一化与门控的线性注意力，存储压缩后的头输出作为第二残差流。
   - **实验结果**：跨模型规模与训练 token 预算，LoomFormer 匹配超过 3x 算力的 Transformer 与近期残差流基线（HC/mHC、MUDDFormer、AttnRes，其训练成本约 1.7–2.8x）。300B token 设置下 LoomPythia-2.8B 实现约 1.6x 平均下游增益，0-shot 持平、5-shot 超越 Pythia-12B。
   - **局限性**：仍需大算力实验验证在更大规模与更长上下文下的可扩展性；垂直注意力的矩阵记忆开销在极端序列长度下的详细权衡未完全披露。
   - **链接**：https://arxiv.org/abs/2611.30634
   </details>

2. **Qwen-Image-HD: Autoregressive Diffusion for High Definition Image Generation（通义高清图像：面向高清的自回归扩散生成）**

   🔬 领域：图像生成 · 视频生成 · 基础模型 · 热度：HF Daily 2026-11-25

   - **一句话核心贡献**：阿里 Qwen 团队提出 Qwen-Image-HD，通过局部训练 + 分块自回归生成，让 Qwen-Image 2.0 在 4K 高清合成上超越直接 4K 生成方案，且训练算力更低。
   - **摘要精译**：
     对完整高清画布做全量微调需要极长的图像序列与巨大计算开销，且在训练资源受限时局部区域会出现不自然的重复条纹。高清生成的成本与质量瓶颈亟待解决。
     Qwen-Image-HD 将 Qwen-Image 2.0 适配到高清合成：每个预测块覆盖 1K 尺度目标 tile，以高清上邻、左邻与压缩历史缩略图为条件，并通过统一画布坐标系统表达空间关系与尺度差异，兼顾局部精细结构与全局概览。
     在 Qwen-Image-Bench 的 4K 评测上，Qwen-Image-HD 的综合表现优于直接 4K 生成（对比 FLUX-3-Image-Klein），相比同骨干的全图 4K 监督微调，生成质量更好、训练算力更低、推理效率更高，重复条纹也更少。还提出 Wavefront-AutoRegressive 推理调度，跨 GPU 并发生成同一条反对角线上的 tile，降低单图延迟。
   - **核心创新点**：
     1. 局部训练+分块自回归避免全图高清微调
     2. 画布坐标统一表达邻域与缩略图条件
     3. 波前自回归调度跨 GPU 并行降延迟

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：每个预测覆盖 1K 目标 tile，条件为上/左高清邻块与压缩历史缩略图（提供相邻精细结构与已生成场景概览），两路历史与目标映射到共享画布坐标系表达空间关系。
   - **实验结果**：Qwen-Image-Bench 4K 上综合优于直接 4K 生成 FLUX-3-Image-Klein；对比全图 4K SFT 相同骨干，训练算力更低、推理效率更高、原始分辨率对比中重复条纹更少。
   - **局限性**：评测集中于 Qwen-Image-Bench 单一基准；跨模型泛化性（DALL·E、Midjourney 系）有待验证。
   - **链接**：https://arxiv.org/abs/2611.32736
   </details>

3. **S-Mind: Internalizing Multi-View Geometry for Spatial Intelligence（S-Mind：内化多视角几何实现空间智能）**

   🔬 领域：多模态 · 空间智能 · 3D 理解 · 热度：HF Daily 2026-11-25

   - **一句话核心贡献**：通过紧凑的空间 token 让多模态大模型内化多视角几何融合与视角变换能力，在四个空间基准上平均精度超越 GPT-6-Astra、Kimi-K3.1-Pro 等前沿通用模型。
   - **摘要精译**：
     空间智能依赖人类认知的两个基石：将多视角融合为一个连贯的 3D 场景、以及在推理过程中将该场景心理变换到新视角。现有 MLLM 即便经过空间微调，两项能力都严重缺失，空间推理成为多模态大模型走向物理世界的瓶颈。
     S-Mind 将多视角几何内化进 MLLM：通过一组紧凑空间 token 监督其持有融合后的 3D 场景，并在推理采用新视角时重新发射这些 token 来表达场景。这一训练注入使空间能力内化为骨干能力，即使推理时收回 token 仍然保持。
     在四个空间基准上，S-Mind 将 Qwen3.5 骨干提升最多 22.26 分，平均精度超越 GPT-6-Astra（+0.45）、Kimi-K3.1-Pro（+1.97）、GLM-5.3-Flash（+7.80）；融合与变换精度达 65.11% 与 82.17%，基线最高仅 16.02% 与 37.28%。推理时比基于工具的 agent 快约 100 倍。
   - **核心创新点**：
     1. 空间 token 内化 3D 场景融合与重表达
     2. 能力内化后即使收回 token 仍保持
     3. 推理速度比工具型 agent 快约 100 倍

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：训练时监督紧凑空间 token 持有融合 3D 场景，推理按视角重发射表达；加载于 Qwen3.5 骨干。
   - **实验结果**：四基准平均精度超越 GPT-6-Astra（+0.45）、Kimi-K3.1-Pro（+1.97）、GLM-5.3-Flash（+7.80）；融合/变换精度 65.11%/82.17% vs 基线最高 16.02%/37.28%；推理约 100x 快于工具型 agent。
   - **局限性**：空间 token 在遮挡、动态场景中的鲁棒性未充分评估；真实机器人部署验证待后续工作。
   - **链接**：https://arxiv.org/abs/2611.28649
   </details>

4. **CoT-Proxy: Cross-Format Transfer for Distilling Long-Horizon Policies（CoT-Proxy：跨格式迁移蒸馏长程策略）**

   🔬 领域：推理 · Agent 后训练 · 模型蒸馏 · 热度：HF Daily 2026-11-25

   - **一句话核心贡献**：证明蒸馏长程策略根本不需要教师模型的思维链——仅用动作轨迹即可迁移能力，通过 CoT-proxy（教师推理短摘要）可将 Qwen3-4B 在 AppWorld 任务成功率提升至 48%。
   - **摘要精译**：
     将推理模型蒸馏为长程 agent，通常需要教师轨迹中的思维链加动作，但最强的教师是闭源模型，思维链隐藏在 API 之后，无法获取。这一信息壁垒是否必要？
     本文证明思维链可以完全省略：学生只在教师动作轨迹上训练，推理块留空，用自身生成的重放缓冲上的 KL 损失限制漂移。由此学得的策略在开启思考的推理阶段可以跨格式迁移——学生以自己的风格推理、像教师一样行动。
     实验显示：蒸馏 Qwen3.6-27B 的动作将 Qwen3-4B 在 AppWorld 上成功率从 7% 提升至 18%（Qwen3-32B 从 12% 到 25%）；引入 CoT-proxy（教师推理的简短摘要）后 Qwen3-4B 可达 35%。蒸馏 GPT-5.6 Luna 的可见输出与推理摘要，将 Qwen3-4B 在 AppWorld 从 7% 提升至 48%、SWE-bench Verified 从 3% 提升至 28%。
   - **核心创新点**：
     1. 无需思维链，仅动作轨迹即可蒸馏
     2. 空推理块 + KL 重放缓冲防止漂移
     3. CoT-proxy 短摘要进一步提升迁移效果

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：学生以教师动作轨迹训练、推理块留空，对自身生成的重放缓冲施加 KL 损失；推理时开启思考产生跨格式迁移；CoT-proxies 为置于空推理块之后的教师推理短摘要。
   - **实验结果**：Qwen3.6-27B→Qwen3-4B：AppWorld 7%→18%；Qwen3-32B：12%→25%；+CoT-proxy：4B→35%；GPT-5.6 Luna→Qwen3-4B：AppWorld 7%→48%、SWE-bench Verified 3%→28%。
   - **局限性**：蒸馏收益衡量偏重 AppWorld/SWE-bench 两个基准；学生推理风格与教师差异带来的行为偏移有待更大范围评估。
   - **链接**：https://arxiv.org/abs/2611.33148
   </details>

5. **On-Policy Codec Distillation for Efficient All-in-One Video Generation（CodecOPSD：视频生成的条件 token 高效蒸馏）**

   🔬 领域：视频生成 · 高效推理 · 热度：HF Daily 2026-11-25

   - **一句话核心贡献**：借鉴视频编解码器思想剪除冗余条件 token，用策略内自蒸馏训练 DiT 适配器，在 16 种条件模态上平均剪掉 66% 的 token，去噪提速 2 倍且质量几乎无损。
   - **摘要精译**：
     现代视觉生成模型基于 token 运作，身份、草图、深度图、运动视频等所有条件输入都要 token 化并拼接进输入序列，条件计算很快成为主导成本，而多数 token 携带冗余时空信息。
     本文核心洞察：判断「什么是真正的新信息」正是经典视频编解码器长期解决的问题。于是先用基于编解码器的 token 剪枝丢弃冗余 token，再用策略内自蒸馏（OPSD）训练 DiT 适配器学习剪枝模式而不损失质量，二者合称 CodecOPSD。
     在自研视频扩散模型上扩展到 16 种条件模态：平均剪除 66% 的条件 token，几乎无质量下降，去噪提速 2 倍，KV cache 模式下缓存内存最多缩减 73%。方法也可迁移到其他 SOTA 预训练图像/视频生成模型，条件越多、帧越长、分辨率越高收益越大。
   - **核心创新点**：
     1. 编解码器启发式 token 剪枝识别真新信息
     2. 策略内自蒸馏适配器无损学习剪枝模式
     3. 平均剪除 66% 条件 token，去噪 2x 提速

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：codec-based token pruning 丢弃冗余时空 token；OPSD 在策略内自蒸馏训练 DiT adapter 复现剪枝模式，避免质量退化。
   - **实验结果**：16 条件模态平均剪除 66% token，去噪 2x 更快，KV cache 模式缓存内存缩减至多 73%；迁移到其他 SOTA 图像/视频生成模型收益随条件更多、帧更长、分辨率更高而增大。
   - **局限性**：token 剪枝率与质量在极端多条件叠加场景的边界未给出严格曲线；仅在自研扩散模型上做了 16 模态全量验证。
   - **链接**：https://arxiv.org/abs/2611.31184
   </details>

6. **Embodied AI Fails the Mirror Test: How a Simple Mirror Breaks Robot Policies（具身智能的镜子测试：一面镜子如何击垮机器人策略）**

   🔬 领域：具身智能 · 机器人操作 · 评测 · 热度：HF Daily 2026-11-25

   - **一句话核心贡献**：受动物认知的镜子自我识别测试启发，构建 RoboDojo-Mirror 基准证明镜像场景会让主流机器人策略成功率普遍下降 10.8–56.7 个百分点，暴露反射感知的共性缺陷。
   - **摘要精译**：
     机器人操作系统能否在包含自身反射的场景中可靠操作物体？作者借鉴动物认知的镜子自我识别测试，系统研究镜面对机器人策略的影响，并发布 RoboDojo-Mirror 基准（保留任务目标、成功标准与策略检查点，对比无镜基线、单镜、双镜与镜面桌面条件）。
     实验覆盖 5 种策略（视觉-语言-行动模型、世界行动模型、agentic 策略），所有镜面条件都降低聚合成功率：三种条件平均下降 10.8–56.7 个百分点，镜面桌面条件下最高下降 62.5 个百分点。对照几何匹配的非反射面板，50–88% 的镜面特有失败未发生机器人-面板接触，说明碰撞不能解释退化——轨迹与接触分析揭示「幻影目标」与真实物体的空间定位错误。
     真实机器人实验（π0.5 与 FastWAM）在立镜与镜面桌面条件下同样成功率更低。这项工作揭示多种机器人策略对反射环境的共性脆弱性，呼吁具身智能评测纳入反射感知。
   - **核心创新点**：
     1. RoboDojo-Mirror 基准系统量化镜面影响
     2. 对照非反射面板分离碰撞与感知因素
     3. 揭示幻影目标与空间错位的共性缺陷

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：基于 RoboDojo 构建单镜/双镜/镜面桌面条件；对照几何匹配非反射面板；轨迹与接触分析 + 定向诊断（镜旁抓取、策略依赖推动进程、主相机遮挡下的物理目标交互）。
   - **实验结果**：5 策略三条件平均成功率下降 10.8–56.7 pp，镜面桌面最高 62.5 pp；50–88% 镜面特有失败无面板接触；真实机器人 π0.5 与 FastWAM 在镜面条件下成功率显著性降低。
   - **局限性**：基准基于 RoboDojo 模拟，真实环境仅验证两种策略；镜面反射强度、视角变化等参数空间未全面扫描。
   - **链接**：https://arxiv.org/abs/2611.33010
   </details>
