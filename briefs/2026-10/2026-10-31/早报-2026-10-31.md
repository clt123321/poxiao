1. **L3G-World: Real-Time Infinite World Generation with Latent 3D Gaussian Memory（L3G-World：潜在 3D 高斯记忆驱动的实时无限世界生成）**

   🔬 领域：视频生成 · 世界模型 · 3D 高斯 · 热度：HF Daily Papers（10-30 批次）

   - **一句话核心贡献**：提出 L3G-World，用"潜在 3D 高斯记忆（L3G）+ 记忆更新器 + 视频扩散 Transformer 自回归交替"实现实时空间一致的世界生成——记忆随场景范围而非流长度增长，达到 SOTA 质量与长程一致性，并以 9 FPS 实时生成。  
   - **摘要精译**：
     交互式世界模型根据用户动作生成视觉内容，但长时程探索中维持空间一致性并实时运行仍是难题。现有方法依赖时序上下文或显式 3D 记忆，二者都因记忆随生成流长度增长而扩展性差；且显式 3D 记忆通过重编码 RGB 渲染来条件化潜在视频生成器，无法做到实时。
     论文提出潜在 3D 高斯记忆（L3G），结合前馈重建效率与紧凑、可快速渲染的场景表示；在此基础上构建 L3G-World，由记忆更新器与视频扩散 Transformer（DiT）自回归交替生成空间一致的世界。记忆更新器在新观测区域生成高斯并精化既有高斯，使记忆随场景范围而非流长度增长；每个高斯还存储一个 VAE 潜在特征，可把记忆直接渲染进 DiT 的潜在空间而无需 VAE 重编码。
     实验表明 L3G-World 在生成质量与长程空间一致性上达到 SOTA：相比此前各指标上最高效的 3D 记忆基线，3D 基元最多减少 38.6 倍、记忆更新快 3.2 倍、记忆渲染快 359 倍，支持 9 FPS 实时世界生成。
   - **核心创新点**：
     1. 记忆随场景范围而非流长增长
     2. 高斯直存 VAE 特征免重编码
     3. 更新器与 DiT 自回归交替生成

   - **方法细节**：L3G 内存 = 前馈重建的高斯集合 + 每高斯一个 VAE latent feature；记忆更新器负责 spawn/refine 高斯，视频 DiT 在潜在空间直接消费渲染出的记忆特征；两者自回归交替，长时程探索时新旧场景无缝衔接。
   - **实验结果**：与最高效 3D-memory 基线逐指标对比：3D 基元最多 -38.6×、内存更新 +3.2× 速度、内存渲染 +359× 速度；生成质量与长程空间一致性 SOTA，9 FPS 实时。

2. **Proving and Improving the Platonic Representation Hypothesis with JEPAs（用 JEPA 证明并改进柏拉图式表示假说）**

   🔬 领域：基础模型 · 表示学习 · 理论证明 · 热度：HF Daily Papers（10-30 批次）

   - **一句话核心贡献**：把"不同模态模型收敛到同一世界表示"的柏拉图式表示假说（PRH）从猜想变为定理——证明分开训练的 JEPA 学到同一表示（差一个旋转），并发现"好视图比 next-token 预测少 42 倍样本即可达到同等对齐"，且 109M 文本 JEPA 的对齐超过所有被评估到 72B 的语言模型。  
   - **摘要精译**：
     不同模态训练的模型是否收敛到同一世界表示是 AI 的核心问题。PRH 猜想规模化后确实如此，但没有证明就没有保证也没有配方。这项工作把假说变成定理。
     首先证明柏拉图式表示定理：任意数量模态上分开训练的联合嵌入预测架构（JEPAs），只要正样本对是同一场景的两次观测（好视图）且错位有界，就能学到同一表示（差一个旋转）。其次证明 next-token 预测是"坏视图"的 JEPA（同一文档的片段），这解释了为何语言模型只能靠规模与视觉对齐。第三，从 145k 条标题到 940M 张网页图像验证理论，发现了能预测未见运行的扩展定律。
     实验上，"好视图"在相同语料上达到同等对齐只需 next-token 预测 42 分之一 的训练样本；109M 参数的文本 JEPA 与 DINOv2、CLIP 图像编码器的对齐优于所有评估过的语言模型（最高 72B），也优于 CLIP 的文本编码器。一次旋转即可把分开训练的编码器变成图像描述器（COCO CIDEr 0.838）；在最新无配对基准上，文本 JEPA 超过所有至 8B 语言模型的零样本准确率（ImageNet-100 top-5 64% vs 至多 56%）。
   - **核心创新点**：
     1. PRH 从猜想升级为定理
     2. 好视图样本效率高 42 倍
     3. 旋转拼接即可做图像描述器

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：三个层次：定理证明（JEPA 正样本对 = 同一场景两次观测且错位有界 → 学习表示差一个旋转）；理论映射（next-token 预测 = 坏视图 JEPA）；规模验证（145k captions → 940M 网页图像，拟合对齐扩展定律并预测未见运行）。
   - **实验结果**：好视图在同等语料上达同等对齐只需 next-token 预测 1/42 样本；109M 文本 JEPA 对齐 DINOv2/CLIP 优于到 72B 的所有 LM 与 CLIP 文本编码器；一次 rotation 成图像描述器 COCO CIDEr 0.838；ImageNet-100 top-5 64% vs LM 至多 56%。
   - **局限性**：定理依赖"好视图/错位有界"的条件，坏视图（如纯文本）收敛路径仍需规模补足；"旋转即可拼接"在任意任务族的普适性待更多模态验证。
   - **链接**：https://arxiv.org/abs/2610.39302

3. **WeVisCut: The Whole Editing Room in One Agent From Narration to Long-Form Video（WeVisCut：从旁白到长视频，一整个剪辑室装进一个 Agent）**

   🔬 领域：视频生成 · 视频编辑 · Agent · 热度：HF Daily Papers（10-30 批次）

   - **一句话核心贡献**：发布 WeVisCut 长视频从脚本到成片系统——Agent 工具执行与策略学习相结合：四阶段数据管线从 3,750 个成品视频反演+复演出 13 万+ 训练样本，单 9B 策略在共享制作状态下协调剪辑并自愈，性能接近 Claude Opus 5 且每个成功输出分钟节省近 33 倍生成 token。

     从旁白生成长视频要求跨镜头保持连贯的相互依赖决策。现有 Agent 式剪辑器多用通用模型驱动的多阶段流水线，紧凑、任务适配策略的质量-成本权衡并不清楚。
     WeVisCut 把工具执行与策略学习打通：Agent harness 维护共享制作状态，工具反馈反过来指导后续决策与修复；因为成品视频不暴露这些决策，四阶段数据管线用"剪辑反演 + 验证式复演"把恢复出的剪辑意图转成可执行的监督信号。这套管线施加在 3,750 个成品视频上，得到 13 万+ 训练样本。
     用这些监督训练单个 9B 策略，在同一个 harness 内协调制作并从中断中恢复。作者还发布 100 任务基准与五类评估剪辑质量与交付可靠性的指标。在共享工具环境下，WeVisCut 大幅超越基础模型，且每个成功输出分钟消耗的生成 token 比 Claude Opus 5 少近 33 倍；在自有指标上也优于任务匹配的原生剪辑器。
   - **核心创新点**：
     1. 剪辑反演+验证复演造监督
     2. 单 9B 策略协调制作与自愈
     3. 100 任务基准 + 五维指标

4. **Intrinsic Distribution Matching（内在分布匹配）**

   🔬 领域：生成模型 · 文生图蒸馏 · 扩散模型 · 热度：HF Daily Papers（10-30 批次）

   - **一句话核心贡献**：在 DMD 分布匹配蒸馏的基础上显式加入高斯矩约束，提出 IDM——用生成器 EMA 副本匹配特征均值与逐坐标标准差，无需外部特征编码器；在 Z-Image-Turbo 6B 与 Qwen-Image 20B 上以两次网络评估即在中英文 LongText-Bench 达 94.25%/90.20%，为该预算下对比方法最高。  
   - **摘要精译**：
     单步与少步文生图必须在有限的精化机会内准确渲染提示词细节。分布匹配蒸馏（DMD）用分数差异把生成分布拉向参考分布；此前工作用内部 velocity 分支估计差异，避免独立的 fake-score 网络。论文提出的问题是：显式的矩约束能否改进这种学习式分数监督。
     把 reverse-KL 场分解为高斯矩分量与非高斯残差，从而识别出可被显式约束的统计量。IDM 保留完整 DMD 校正，并用生成器指数移动平均（EMA）副本匹配特征均值与逐坐标标准差，全程不需要外部特征编码器。
     实验覆盖全参数与 LoRA 两种调优，模型为 Z-Image-Turbo 6B 与 Qwen-Image 20B。两次网络评估下，IDM 在中英文 LongText-Bench 分别达到 94.25% 与 90.20%，为同等预算下对比方法最高；受控消融证实新增矩损失的增益，且生成器 EMA 特征在五项报告指标上与外部 DINOv2 编码器竞争相当。
   - **核心创新点**：
     1. 高斯矩约束叠加 DMD 校正
     2. EMA 副本替代外部特征编码器
     3. 中英文 LongText-Bench 同预算最高

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：reverse-KL 场分解出高斯矩分量与残差，明确哪些统计量可显式约束；IDM = 完整 DMD 校正 + EMA 副本匹配 feature means 与 per-coordinate standard deviations；无外部 encoder，支持 full-parameter 与 LoRA 两种配置。
   - **实验结果**：两次网络评估：LongText-Bench 中文 94.25%、英文 90.20%（对比方法中该预算最高）；消融显示矩损失有增益；EMA 特征对照 DINOv2 在五指标上竞争力相当。代码：https://github.com/inclusionAI/IDM
   - **局限性**：优势集中在"两次网络评估"预算口径，更大推理预算下的领先幅度未披露。

6. **Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs（需要时才看：证书引导的视觉路由实现高效 Diffusion VLM）**

   🔬 领域：多模态 · Diffusion VLM · 推理效率 · 热度：HF Daily Papers（10-30 批次）

   - **一句话核心贡献**：发现视觉 token 在 Diffusion VLM 输入中占 89-97%，但删掉图像平均只影响 22.8% 的解码步（最低 7.9%），据此提出免训练免调参的 LOWN 解码法——只在无图预测与既有图像条件预测不一致时才处理图像，保留 LLaDA-V 99.6% 分数、平均仅用 35.3% 解码 FLOPs。  
   - **摘要精译**：
     Diffusion VLM（DVLM）在每个去噪步处理全部输入。研究基准上视觉 token 占输入 89-97%，意味着大部分解码计算在反复处理同一张图像。视觉 token 剪枝方法用移除部分视觉 token 部分缓解负担，但丢失被移除的信息，且剩余图像仍每步处理。
     为测图像到底多常被需要，作者对比 LLaDA-V 每步解码有无图像时的预测：移除图像平均只在 22.8% 的步骤改变被 unmask 的 token（最低仅 7.9%）。据此提出 LOWN：每一步决定是否处理图像、以及 unmask 多少 token。LOWN 先无图预测 masked tokens，仅当该预测与上次图像条件预测不一致时才处理图像；一致性即为"证书"，被认证的 token 数决定该步 unmask 的个数。
     由于不同基准对图像的需求不同，LOWN 的自适应决策是必要的，固定调度不可行。无需训练、无需调阈值，LOWN 在 10 个基准上保留 LLaDA-V 99.6% 分数，平均只用 35.3% 解码 FLOPs；还能跨 LLaDA 系 DVLM 泛化、与视觉 token 剪枝正交组合、配合 KV caching 进一步提效。
   - **核心创新点**：
     1. 无图预测分歧触发看图
     2. 一致性证书决定 unmask 数
     3. 免训练免调参 99.6% 分数保留

   <details>
   <summary>💡 展开详情（方法论 + 实验）</summary>

   - **方法细节**：LOWN 每步先做无图预测，与上一图像条件预测比对，agreement 即 certificate（可复用）；分歧时才处理图像并重新 unmask；certified tokens 数量决定该步 unmask 数；benchmark 间图像需求差异大 → 自适应决策优于固定 schedule。
   - **实验结果**：10 benchmark 平均保留 LLaDA-V 99.6% 分数 @ 35.3% 平均解码 FLOPs；图像移除平均影响 22.8% 步（min 7.9%）；跨 LLaDA 系 DVLMs 泛化、与 visual token pruning 正交、配合 KV cache 进一步提效。
   - **局限性**：结论建立在 LLaDA 系 DVLM 与特定基准集上，对其他 DVLM 架构与更长上下文的推广性未验证。
   - **链接**：https://arxiv.org/abs/2610.36671

   </details>

7. **Read, Allocate, Route: Role-Coupled Tokenization for Pixel-Space Generative Transformers（读取、分配、路由：像素空间生成 Transformer 的角色耦合分词）**

   🔬 领域：基础模型 · 图像生成 · 架构设计 · 热度：HF Daily Papers（10-30 批次）

   - **一句话核心贡献**：提出像素空间生成 Transformer 新架构 SpecSlot——用 DCT 系数谱带把"细节密度"与"全局注意力序列长度"解耦：每锚点扩成多槽位、各分一段低频系数，仅最低频槽参与全局注意力；ImageNet-512 上 FID 比 FLOPs 匹配的对照提升 2.84 且少 3.9% FLOPs，以 JiT-B/16 38.2% 的成本逼近其质量。

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：观察发现"更细的细节不必然需要更多全局通信"——低频结构受益于全局交换，高频细节可局部建模；SpecSlot 将每个空间锚点扩展为多个 slots，每个 slot 分配一段不相交的 DCT 系数带（分离锚点密度与频谱细分）；只有每锚点最低频 slot 参与全局注意力，其余 slot 局部交互；空间 head 做局部修正，生成状态/目标/损失仍留在像素空间。
   - **实验结果**：ImageNet-256 与 FLOPs 匹配的 JiT 对照 FID 相当但收敛更快；ImageNet-512 FID -2.84 @ -3.9% FLOPs；对 JiT-B/16 仅差 0.69 FID 而成本低 38.2%；文生图 DPG-Bench 超 JiT-B/8 达 1.06 @ -40.6% 前向成本。
   - **局限性**：报告相对 FLOPs-matched 对照与控制模型的相对优势，绝对 SOTA 语境未展开。
   - **链接**：https://arxiv.org/abs/2610.40647

   </details>
