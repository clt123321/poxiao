1. **Visual Latents Know More Than They Say: Unsilencing Latent Reasoning in MLLMs**

   🔬 领域：多模态推理 · 视觉语言模型 · 热度：推理机制新发现，8 Benchmark 验证

   - **一句话核心贡献**：发现 MLLM 中"视觉潜态被沉默"的系统性优化病态——视觉潜态训练中变得语义丰富却被系统性压制——通过两阶段推理时优化无需参数更新即可释放被压制的推理能力。
   - **摘要精译**：连续潜态空间推理提供文本 CoT 的紧凑替代，但作者发现现有方法的优化病态：自回归目标在共享参数空间中倾向快捷路径（直接视觉输入），将潜态 token 推向过渡态而非信息性推理内容，称为"沉默视觉潜态"。Stage I：查询引导对比潜态-视觉对齐预热视觉潜态，防止 latent collapse；Stage II：置信度进度奖励，激励预测 token 分布沿潜态跨度逐步集中，让预测真正通过潜态推理而非绕过它。8个 Benchmark、4个模型骨干验证，无参数更新即有效释放压制的推理容量。
   - **链接**：https://arxiv.org/abs/2605.02735v1

   - **核心创新点**：
     1. 首次命名并系统描述"沉默视觉潜态"现象
     2. 推理时优化（inference-time），骨干参数完全冻结
     3. 置信度进度奖励：将分布集中化作为奖励信号，新颖且直接有效
   - **实验结果**：8个 Benchmark，4个骨干（包含不同规模 MLLM），一致性改善
   - **局限性**：推理时优化引入额外计算，实际部署需权衡延迟

2. **MolmoAct2: Action Reasoning Models for Real-world Deployment**

   🔬 领域：具身智能 · VLA · 开源机器人 · 热度：全面开源、超越 GPT-5 的 VLA

   - **一句话核心贡献**：首个为实用部署设计的完全开源 VLA，MolmoER 在 13 项具身推理 Benchmark 超越 GPT-5 和 Gemini Robotics ER-1.5，720 小时双臂轨迹数据集开源。
   - **摘要精译**：当前 VLA 存在以下问题：前沿闭源、开权重依赖昂贵硬件、推理增强延迟过高、微调成功率不达实用门槛。MolmoAct2 五轴突破：① MolmoER——3.3M 样本具身推理专用 VLM 骨干（specialize-then-rehearse）；② 三个新数据集含 720 小时遥操作双臂轨迹（迄今最大开放双臂数据集）；③ OpenFAST——五种机器人形态的开源动作 tokenizer；④ flow-matching 连续动作专家接入离散 token VLM（per-layer KV-cache 条件化）；⑤ MolmoThink——仅对变化场景区域重预测深度 token，大幅降低延迟。7个仿真+真实世界 Benchmark 优于 Pi-05，13项具身推理 Benchmark 超越 GPT-5 和 Gemini Robotics ER-1.5。
   - **链接**：https://arxiv.org/abs/2605.02881v1

   <details>
   <summary>💡 展开详情</summary>

   - **核心创新点**：MolmoThink 自适应深度推理；全栈开源（权重+代码+数据）；OpenFAST 跨形态 tokenizer
   - **实验结果**：13项具身推理超越 GPT-5 + Gemini Robotics ER-1.5；7个 VLA Benchmark 优于 Pi-05
   - **局限性**：数据集偏特定平台（Franka/SO100），跨平台迁移成本待评估

3. **AI-Generated Smells: Volume-Quality Inverse Law in AI-Driven Software**

   🔬 领域：AI 软件工程 · 代码质量 · 热度：直击 Vibe Coding 核心痛点

   - **一句话核心贡献**：AI 生成代码的技术债务系统审计揭示"体量-质量反向法则"：代码体量是结构退化的近乎完美预测指标，能力越强的模型生成越臃肿耦合的代码。
   - **摘要精译**：LLM 的 AI 软件工程潜力通常以功能正确性衡量，忽视长期可维护性。本研究识别 AI 引入的"机器签名"缺陷，建立"推理-复杂度权衡"：模型能力越强，生成越臃肿耦合。"体量-质量反向法则"：代码量是结构退化的近乎完美预测指标。关键发现：功能正确性和详细提示都无法缓解退化。这挑战提示驱动范式，将问题从代码生成重定位为架构复杂性管理。未来进展需要让 Agent 具备显式架构预见能力。
   - **链接**：https://arxiv.org/abs/2605.02741v1

4. **Bolek: Multimodal Language Model for Molecular Reasoning (药物发现)**

   🔬 领域：科学 AI · 分子推理 · 热度：注入分子指纹嵌入的轻量多模态模型

   - **一句话核心贡献**：注入 Morgan 指纹嵌入的紧凑多模态 LM，在 15 个 TDC 分类任务平均 ROC/PR AUC 从 0.55 提至 0.76，尽管不足 TxGemma 一半参数量却在 13/15 任务上超越它。
   - **摘要精译**：分子属性模型在高风险药物发现决策中越来越重要，但其输出难以审计：经典预测器无解释，LM 生成的解释与分子结构弱关联。Bolek 将 Morgan 指纹嵌入注入指令调优文本解码器，微调于分子对齐任务（描述生成、RDKit 描述符预测、子结构检测）以及15个 TDC 二分类任务的合成 CoT 推理。Bolek 引用数值描述符的频率是基准 LLM 的10-100倍，与 RDKit 强相关（Spearman rho=0.87-0.91）。15个未见过的 TDC 分类任务上泛化良好。
   - **链接**：https://arxiv.org/abs/2605.02745v1

   <details>
   <summary>💡 展开详情</summary>

   - **核心创新点**：Morgan 指纹嵌入作为模态注入；合成 CoT 锚定具体分子特征
   - **实验结果**：AUC 0.55→0.76；TxGemma-9B-Chat 13/15任务被超越（参数量不足其一半）
   - **局限性**：主要聚焦二分类任务，复杂多步分子设计任务适用性待扩展
   - **链接**：https://arxiv.org/abs/2605.02745v1

   </details>

5. **An Empirical Study of Agent Skills for Healthcare: Practice, Gaps, and Governance**

   🔬 领域：医疗 AI Agent · Skills 生态 · 热度：首个医疗 Agent Skills 实证分析

   - **一句话核心贡献**：首次对医疗 Agent Skills 进行实证分析（57,159 个公开 skills 中筛出 557 个），发现公共 skills 侧重患者工作流自动化而非诊断/治疗，临床风险未被通用技术风险框架覆盖。
   - **摘要精译**：医疗自动化受本地流程和组织限制，Agent 能力难以跨场景直接迁移。Agent Skills（为 AI Agent 打包可复用流程的自包含目录）正成为医疗 Agent 跨场景适配的程序层。本研究分析来自 ClawHub 的 557 个医疗相关 skills，沿功能、部署上下文、自主性、安全性十维度标注。发现：公共医疗 skills 侧重患者工作流和监控，而非医疗 Agent 研究关注的诊断/治疗任务；医疗生命周期和专业临床输入覆盖不均；通用技术风险不可靠地捕获临床风险。
   - **链接**：https://arxiv.org/abs/2605.02709v1
