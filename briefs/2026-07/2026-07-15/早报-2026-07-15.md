### Tier 1 · 核心突破

1. **函数感知填空中训练（Function-Aware FIM）：编程 Agent 基础模型的中期训练**

   🔬 领域：代码 Agent · LLM 训练 · 工具调用 · 热度：HF Top 1

   - **一句话核心贡献**：提出将编程 Agent 的"调用-观测-续写"循环重建为函数调用填空（FIM）训练信号，解决标准从左到右预训练无法有效习得工具返回值整合能力的结构性问题。
   - **摘要精译**：
     编程 Agent 需要将外部工具返回结果整合到持续推理中；标准代码预训练从左到右暴露函数调用，但只在前向方向，无法充分学习"工具返回值如何影响后续推理"。
     本文发现 Agent 的动作-观测-续写循环与函数调用位置在结构上同构，提出函数感知 FIM 作为中期训练目标：模型学习在函数调用处预测函数体（工具调用）并利用返回值续写推理。
     在代码 Agent benchmark（SWE-bench、HumanEval-Agent）上，函数感知 FIM 中训练后，模型在工具调用整合和多步推理上分别提升 11% 和 8%。
   - **核心创新点**：
     1. 发现 Agent 循环与 FIM 结构同构，创新中期训练信号
     2. 无需额外 Agent 轨迹数据，从代码本身挖掘训练信号
     3. 工具调用整合提升 11%，多步推理提升 8%

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：在函数调用位置插入 FIM mask，训练模型预测函数实现（对应工具调用）并用返回值进行续写；作为基础预训练后的中期训练阶段，数据来自开源代码库。
   - **实验结果**：SWE-bench 解决率 +11.2%，HumanEval-Agent 完成率 +8.4%，代码补全基础能力无损。
   - **局限性**：仅适用于有明确函数调用结构的代码，对非结构化 Agent 动作空间（如浏览器操作）的适用性待验证。
   - **链接**：https://arxiv.org/abs/2607.12463

   </details>

2. **超越可教边界的搜索：进化视觉生成的知识边界**

   🔬 领域：视觉生成 · 知识边界 · 开放世界生成 · 热度：HF Top 2

   - **一句话核心贡献**：提出知识边界进化框架，通过网络搜索获取新知识来解决视觉生成模型"知识截止后"对新角色、趋势实体无法准确生成的结构性问题。
   - **摘要精译**：
     视觉生成器擅长渲染，但对训练截止时间之后的新知识（新角色、趋势事件、流行文化符号等）只能自信地"捏造"；这一世界知识瓶颈是结构性的，因为生成器在固定语料上训练，而视觉世界是开放演化的。
     本文构建知识边界进化框架：当检测到生成器知识不足时，主动通过搜索引擎获取外部视觉参考并整合到生成过程，让生成器能够实时生成训练截止后的新实体。
     在开放世界视觉生成 benchmark 上，相比无搜索基线，新实体生成准确率提升 38%，同时已知实体生成质量无损。
   - **核心创新点**：
     1. 知识边界主动检测与外部搜索整合
     2. 无需重新训练，运行时扩展知识边界
     3. 新实体生成准确率提升 38%

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：训练知识边界检测器判断生成器对当前请求的"知识充足度"；对不足的情况触发搜索，检索最相关视觉参考；将参考图像作为条件信号注入生成过程。
   - **实验结果**：在"后截止日期实体"测试集上准确率从 32% 提升至 70%，CLIP-Score 提升 0.18，已知实体无下降。
   - **局限性**：搜索延迟增加响应时间；版权和隐私问题需要处理；检索质量受搜索引擎结果质量影响。
   - **链接**：https://arxiv.org/abs/2607.05382

   </details>

3. **Read It Back：预训练 MLLM 作为文本-图像生成的零样本奖励模型**

   🔬 领域：视觉生成 · RL 奖励 · 训练无关 · 热度：HF Top 3

   - **一句话核心贡献**：提出 SpectraReward，通过测试"原始提示词能否从生成图像中被恢复"来度量图文对齐质量，将任意预训练 MLLM 转化为零样本视觉生成奖励模型，无需专门训练奖励模型。
   - **摘要精译**：
     图像生成强化学习需要可靠的奖励信号来度量生成图像与提示词的对齐质量；训练专用奖励模型成本高且容易过拟合，现有方法（VQA判断、问题分解验证）依赖对图像内容的直接推理，存在视觉幻觉问题。
     SpectraReward 另辟蹊径：给 MLLM 看生成的图像，让它重建原始提示词，以重建准确性作为对齐质量的间接测量；这一"读回来"信号利用 MLLM 预训练的语言-图像对齐能力，天然是零样本的。
     在 HPSv2 等图像生成偏好 benchmark 上，SpectraReward 作为奖励信号的效果超越专门训练的奖励模型，且完全无需任何奖励模型训练。
   - **核心创新点**：
     1. "读回来"间接奖励信号，巧妙规避直接图像判断的幻觉问题
     2. 任意预训练 MLLM 即可使用，零额外训练成本
     3. HPSv2 benchmark 超越专训奖励模型

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：给定生成图像，将其送入 MLLM 并让其重建原始提示词；计算重建提示词与原始提示词的语义相似度作为奖励信号；可直接用于 RLHF 或 DPO 数据筛选。
   - **实验结果**：HPSv2 对齐评分 0.312（vs 专训奖励模型 0.298），且无需任何奖励模型训练数据。
   - **局限性**：对提示词细节描述准确性有依赖；极复杂提示词的重建难度大，奖励信号质量下降。
   - **链接**：https://arxiv.org/abs/2607.11886

   </details>

   - **一句话核心贡献**：发布开源多乐器音乐转录模型 MuScriptor，解决现有方法在复杂真实音乐混音场景下泛化差的问题，在多乐器真实录音上达到实用水平。

   <details>
   <summary>💡 展开详情</summary>

5. **让 RGB 成为视觉语言**

   - **一句话核心贡献**：提出将各类视觉任务（分割、深度、法线等）统一为 RGB 图像-到-RGB 图像的编辑问题，用一套统一 RGB 表示消除不同任务头和输出格式的碎片化。

## 📊 今日总结

1. **编程 Agent 的核心能力提升需要专门的训练信号设计**：函数感知 FIM 揭示了工具调用整合能力无法从通用预训练中自然涌现，需要与 Agent 工作流结构对齐的专门信号；背后逻辑是 Agent 的"调用-观测-续写"循环在结构上与 FIM 同构，利用这一对应关系设计训练信号是低成本高收益的方向；预计精细化 Agent 训练信号设计将成为 2026-2027 年代码 LLM 研究的核心方向。

2. **零样本奖励模型是 AI 对齐研究的重要效率突破**：SpectraReward 将"读回来"作为奖励信号，不需要任何奖励模型训练数据就能超越专训模型；背后逻辑是预训练 MLLM 已习得足够的语言-视觉对齐能力，只需设计合适的间接度量方式即可利用；预计零样本奖励模型范式将扩展到文本、视频等其他模态，大幅降低 RLHF 数据标注成本。

3. **视觉生成知识边界问题是产品层面的系统性挑战**：视觉 RAG 提供了技术路径，但版权处理是商业化的主要障碍；预计 2026-2027 年视觉内容许可和版权管理 API 将成为重要基础设施，类似于文本 RAG 中的知识库授权管理服务。
