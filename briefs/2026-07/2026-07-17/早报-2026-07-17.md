### Tier 1 · 核心突破

1. **LongStraw：固定 GPU 预算下突破 200 万 Token 的长上下文 RL**

   🔬 领域：长上下文 · RL 训练 · LLM 扩展 · 热度：HF Top 1

   - **一句话核心贡献**：解决 RL 后训练与推理上下文长度的"断层"问题，在固定 GPU 预算下将 RL 后训练上下文推进到 200 万 token，使 RL 训练的长度与推理部署真正对齐。
   - **摘要精译**：
     推理系统的上下文长度正接近百万 token，但 RL 后训练普遍停留在 256K token 以下，依赖"推理时长度泛化"这一不稳定的假设；对于需要处理长轨迹的 AI Agent，这一断层尤为关键。
     LongStraw 提出固定 GPU 预算下的长上下文 RL 训练策略：通过智能序列分桶、梯度检查点优化和分布式 KV Cache 复用，在不增加 GPU 数量的情况下将 RL 训练长度扩展到 200 万 token。
     在长上下文 Agent 任务和长文档推理 benchmark 上，LongStraw 相比 256K RL 训练+泛化的基线提升 12-18%，对超长输入的稳定性大幅改善。
   - **核心创新点**：
     1. 固定 GPU 预算下 RL 训练扩展到 200 万 token
     2. 智能序列分桶+梯度检查点优化消除内存瓶颈
     3. 长上下文 Agent 任务提升 12-18%

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：序列分桶策略根据长度动态分配显存；梯度检查点覆盖 RL 特有的 rollout-backprop 流程；KV Cache 在分布式节点间复用以减少冗余计算。
   - **实验结果**：RULER 2M-token benchmark：LongStraw 77.3% vs 256K RL+泛化 65.8%；长文档代理任务完成率 +14.6%。
   - **局限性**：序列分桶在批量差异极大时效率下降；200 万 token RL 训练对数据质量要求极高。
   - **链接**：https://arxiv.org/abs/2607.14952

2. **VideoChat3：全开放、高效、通用的视频多模态大语言模型**

   🔬 领域：视频理解 · MLLM · 开源模型 · 热度：HF Top 2

   - **一句话核心贡献**：发布完全开放（数据+代码+权重）的视频 MLLM，实现在运动理解、长视频和流式交互三类视频场景的统一处理，是目前最全面的开源视频理解模型。
   - **摘要精译**：
     视频理解覆盖短片运动分析、长视频叙事理解和实时流式交互三类本质不同的场景，现有开源模型普遍只在其中一到两类场景表现出色。
     VideoChat3 通过分阶段训练（运动感知→长视频理解→流式适配）和统一模型架构，在三类场景下均达到 SOTA 或接近 SOTA 水平，且完全开源（Apache 2.0）。
     在 MVBench（运动）、Video-MME-Long（长视频）和 StreamBench（流式）三个代表性 benchmark 上，VideoChat3 分别排名前三，是首个在三类场景均具竞争力的开源视频模型。
   - **核心创新点**：
     1. 三类视频场景统一处理（运动/长视频/流式）
     2. 完全开源（数据+代码+权重，Apache 2.0）
     3. 三 benchmark 均排名前三

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：三阶段训练课程：Phase 1 大规模视频图文对预训练；Phase 2 运动+长视频混合指令微调；Phase 3 流式交互适配（sliding window attention）。
   - **实验结果**：MVBench 72.8%（行业第一），Video-MME-Long 64.2%（第二），StreamBench 71.6%（第二）。
   - **局限性**：流式模式延迟仍高于专用流式模型；超过 2 小时的超长视频处理效果下降。
   - **链接**：https://arxiv.org/abs/2607.14935

   </details>

3. **SEED：Agent 强化学习的自进化在线策略蒸馏**

   🔬 领域：Agent · 在线策略蒸馏 · 强化学习 · 热度：HF Top 3

   - **一句话核心贡献**：提出 SEED 框架，通过自进化在线策略蒸馏解决 Agent RL 稀疏轨迹级奖励导致的学习效率低下问题，结合工具调用和环境反馈实现密集监督信号生成。
   - **摘要精译**：
     长时序 Agent 任务的结果级稀疏奖励导致 RL 学习效率极低，尤其对于工具调用和多轮交互任务；步骤级监督需要人工标注，成本极高。
     SEED 利用强教师模型在训练过程中实时生成密集步骤级监督信号，通过在线蒸馏让学生 Agent 模型从密集信号中快速学习，同时利用学生反馈迭代改进教师信号质量，形成自进化闭环。
     在 Tool-Bench 和 WebArena 等 Agent benchmark 上，SEED 相比标准 RL 基线平均提升 16%，训练样本效率提升约 4 倍。
   - **核心创新点**：
     1. 教师实时生成密集步骤监督信号，消除稀疏奖励问题
     2. 学生反馈迭代改进教师，自进化闭环
     3. Agent 任务平均提升 16%，样本效率 4 倍提升

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：强教师模型（GPT-4o 或大型开源模型）观察学生轨迹并生成步骤级评分和修正建议；学生通过 KL 散度约束接收蒸馏信号；定期用学生成功轨迹更新教师 few-shot 示例。
   - **实验结果**：Tool-Bench 工具调用成功率：SEED 81.3% vs 标准 RL 70.2%；WebArena 任务完成率：SEED 38.6% vs 标准 RL 32.1%。
   - **局限性**：依赖强教师模型质量；教师生成的密集信号成本较高；自进化可能放大教师的系统偏差。
   - **链接**：https://arxiv.org/abs/2607.14777

   </details>

### Tier 2 · 工程改进

4. **世界-动作模型的安全隐患：BadWAM 研究**

   🔬 领域：具身 AI 安全 · 世界模型 · 红队测试 · 热度：HF Top 5

   - **一句话核心贡献**：发现世界-动作模型（WAM）存在"世界预测准确但动作执行错误"的独特安全漏洞——攻击者可通过对抗样本使 WAM 生成表面上合理但实际有害的动作序列。

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：设计针对 WAM 的对抗攻击，在保持视频预测逼真度的同时扰动动作输出；发现世界预测和动作输出的耦合方式存在可被利用的解耦点。
   - **实验结果**：在 RoboMimic 和 MetaWorld 任务上，BadWAM 攻击成功率 73%，同时视频预测 FID 与正常运行相比仅下降 0.3。
   - **链接**：https://arxiv.org/abs/2607.15207
   </details>

5. **SearchOS-V1：鲁棒开域信息搜索 Agent 协作**

   🔬 领域：搜索 Agent · 多 Agent 协作 · 信息搜索 · 热度：HF Top 4

   - **一句话核心贡献**：提出多 Agent 协作搜索框架，解决单 Agent 在长交互历史下任务进展追踪失效和搜索失败循环的问题，通过专职任务追踪 Agent 和失败感知重规划实现鲁棒搜索。

   <details>
   <summary>💡 展开详情</summary>

   - **方法细节**：分离"搜索执行 Agent"和"任务追踪 Agent"职责；追踪 Agent 维护结构化任务状态图；失败感知模块检测搜索循环并触发策略重规划。
   - **实验结果**：在 OpenDomain-Search benchmark 上多跳问题完成率 67.3%（vs 单 Agent 52.8%），长交互（>10 轮）完成率提升最显著（+22%）。
